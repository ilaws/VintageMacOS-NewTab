# Hello! This is my "New Tab" application!

This was made using HTML, CSS, and Javascript (JS is for widgeting). It isn't really complicated (except for some of the CSS 😣).

This is made to look like vintage versions of MacOS. I am currently working on another Stardance project, turning modern Intel hardware to be compatible with older PowerPC Mac operating systems without having to install a bunch of apps. So, I thought it was fitting.

## Specifications

- Font Family: "Lucida Grande" (Google told me apple used it or something).
- NASA API's: APOD, EPIC.
- Weather API: https://api.open-meteo.com/v1/forecast

## How to run on your system

Please run locally. I don't know how to set up a .env, nor how to use a gitignore. I don't even know what a git is besides it being in Github's name. If you don't run it locally, there is a risk of your NASA API key getting leaked.

Basically, all you have to do is place your API key into Config.JS and you should be good to go :).
